# Acer Sense Linux

Альтернативна панель керування для ноутбуків Acer під Linux (написана на Python/PyQt6).
Створено спеціально для керування апаратними фічами, які зазвичай доступні тільки у Windows.

## Можливості
* **Режими живлення:** Інтеграція з `powerprofilesctl` (Бесшумно, Обычный, Производительность).
* **Охолодження:** Автоматичне перемикання профілів кулерів (запис байтів напряму в EC).
* **Батарея:** Апаратне обмеження зарядки до 80% для збереження ресурсу акумулятора.
* **Мікрофон:** Синхронізація LED-індикатора мікрофона (через `hda-verb`).
* **Моніторинг:** Температура, завантаженість RAM, SSD/NVMe дисків (підтримка Btrfs/Ext4/NTFS).
* **Швидка діагностика:** стан акумулятора, доступний ECC, температура, вільне місце та безпечна SMART-перевірка без пробудження диска.
* **Екран:** BluelightShield (потребує `hyprsunset` або `wlsunset`).

## Встановлення (Arch Linux / AUR)
Проєкт підготовлено для пакування в AUR.
```bash
git clone https://github.com/ТВІЙ_ЮЗЕР/acer-sense.git
cd acer-sense
makepkg -si
```

`smartmontools` є необов'язковою залежністю: без нього діагностика працює, але SMART-статус накопичувача не відображається. Перевірка не запускає стрес-тести та не записує дані на накопичувачі.
